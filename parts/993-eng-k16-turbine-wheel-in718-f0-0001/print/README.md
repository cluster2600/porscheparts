# Print it: K16 turbine wheel, display mock-up

<img src="mockup.png" alt="K16 turbine and compressor wheel mock-ups on their display stand" width="700">

> [!CAUTION]
> **Display mock-up only — never in a turbocharger.** The turbine wheel is
> `prohibited_pending_engineering`; MOCK-UP / NOT FOR USE is engraved into its
> back ([decision 0011](../../../docs/decisions/0011-printable-display-mockups-of-prohibited-parts.md)).

This wheel is printed as a pair with the K16 compressor wheel, on a shared
display stand. Everything — the plate, the stand, settings and instructions —
is in the compressor wheel's folder:
**[`993-eng-k16-compressor-wheel-al2139-f1-0001/print/`](../../993-eng-k16-compressor-wheel-al2139-f1-0001/print/README.md)**.
