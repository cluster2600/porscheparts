## Vérification de la symétrie

La symétrie est une hypothèse tant qu'elle n'est pas mesurée. Avant tout miroir :

1. mesurer D01 à D05 sur l'exemplaire présent ;
2. mesurer les mêmes interfaces sur le côté dépourvu de cache ;
3. consigner tout écart comme contradiction dans la fiche de mesure ;
4. n'appliquer le miroir que si les écarts restent dans l'incertitude déclarée.
