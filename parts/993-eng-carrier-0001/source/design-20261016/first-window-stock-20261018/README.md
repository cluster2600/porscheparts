It proposes 132 byte-for-byte payload files, totaling 54,767,267 bytes. No
payload has been copied, packed, published or regenerated by this preparation.

`parts/993-eng-carrier-0001/source/design-20261016/first-window-stock-20261018/`.
A separate ROOT review and GO are required before any delivery operation.

## Reproduction and runtime limits

The capsule is proposed as an exact geometry/source/evidence handover, not an
already replayed standalone generator. Original scripts and controls retain
their historical absolute paths and SHA-256 values. In particular,
`build_stock.py` has an absolute `SOURCE` path. It can be called independently
of `trial.py`; rerunning `trial.py` would also repeat the rejected union and
is not a stock-only reproduction command.

A future regeneration proposal should restore the same relative source/input
tree, apply one declared path-only rebase of `build_stock.py`'s `SOURCE`, and
call its existing `build()` under a separate bounded review. The preserved
correction builder then selects the adjacent private `normal-builder` through
its existing `BASE` seam. Such a rebase and native replay have not been
implemented or executed here. No copied source is silently rewritten.

Native runtimes are external. The preserved original control maps pin their
actual files. Metadata read without importing the packages records build123d
0.11.1, cadquery-ocp-novtk 7.9.3.1.1 and the two original NumPy environments.
Neither a runtime archive nor a portable native replay is claimed. Repository
licence and provenance files are included; the delivery creates no new
licence or manufacturing permission.

## Proposed byte-copy protocol

After a separate GO, reuse the reviewed exclusive stable-FD copy pattern in
`work/carrier-C1-terminal-taper-publication-preparation-003/copy_durable.py`.
Only its fixed inventory, target, GO and result identities need a new declared
version. Require canonical relative regular paths with no symlinks, a fresh
target, matching FD/path identities before and after each read, exclusive
writes, fsync, complete destination rehash and unchanged source identities.
The final `archive.json` inventories the exact durable file set and excludes
itself. Its future SHA-256 is NULL until it is actually written and closed.

This packet does not contain a copy controller or an armed launch. The later
controller must preserve all 132 listed source bytes and separately include
the final English README, artifact-role map and reviewed inventory. No ZIP is
needed for the current 54.8 MB loose-file handover. No catalogue, figure,
tracked-document, stage, commit or public-release action is proposed.

The shortest later protected/T10 adaptation is recorded in `NEXT-STAGES.md`.
