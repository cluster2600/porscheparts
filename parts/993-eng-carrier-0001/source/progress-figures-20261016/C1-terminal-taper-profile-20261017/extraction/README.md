# Preserved taper: new-only section and same-solid volumes

This preparation is not armed. It imports the preserved raw taper BREP `dde710a2…` once, measures three native volume overloads on its one valid Solid, and extracts only its section in the exact closed oblique plane used for figure 25. It does not rebuild CAD, remesh, solve FEA, or recompute the closed baseline and original-C1 profiles.

The native section body is retained without an AST change from [figure revision 003](../carrier-C1-junction-section-figure-003/figure.py). It uses the same native section settings, complete edge traversal, and 0.001 mm drawing deflection. All resulting edge curves and drawing points are retained. The closed profiles are reused in full with their original role labels and source context; their actual export command, producer, plan, receipt and successful owned supervision must still join through the original `closed_extraction()` check.

The unchanged `evaluate()` function in [the retained volume diagnostic](../carrier-process-20261017/bounded-webs-BREP-volume-method-diagnostic-preparation-001/compare.py) is imported without calling its `main()` or `compare()`. It measures `(False, False, False)`, `(True, False, False)` and `(1e-10, True, False)` on the same actual imported Solid. Each actual volume, binary64 hex value and native returned error is written before the adaptive-reference gate. The adaptive result must exactly equal the closed forward value **285602.88227244973 mm³**. This supplies a new measured nonadaptive volume; it does not supply a Gmsh `getMass` value or prove an absence of import healing. No new T10 mesh has been run.

The forward reference is bound to its [independent ROOT closure](../carrier-process-20261017/bounded-webs-C1-terminal-taper-native-screen-preparation-001/root-terminal-review-001.json), actual assessment, and volume authority for the same BREP. Original post-Build law RC1 remains unchanged. The candidate remains unqualified; inverse/topology, protected interfaces, STEP readback and FEA remain separate gates.

The old C1 normal/ray and its intersections are reference observations only. No new taper ray is computed, no old ray is relabelled as the new surface normal, and no global thickness claim is made. The exact section plane still refers to the closed coarse peak 84037/IP1; the later H2 peak is not substituted.

Proposed bounds are one process, no workers, native pool/BLAS one, child nice 10, 180 s owned outer budget, 150 s inner alarm and CPU soft/hard 140/160 s. The unchanged `4d18` supervisor retains its 10+10 s owned cleanup, reaping, group checks, and source hashes. Output and supervision directories must be fresh. Only ROOT review and a distinct strict arming step can make this preparation executable.

They preserve the native-body AST, binding refusals, exact overload arguments and same-object calls, and reject invented Gmsh volume or thickness/admission claims. These are synthetic source checks, not native measurements. The initial incomplete synthetic fixture and the pre-volume source are retained under `history/`.

Rendering is not part of this native extraction and requires separate review.
