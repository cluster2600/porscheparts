# Figure 32 — first-window stock geometry comparison

This figure compares two actual STL exports with the same whole-part camera and scale, followed by four matched XY closeups of the first window on the two mirrored arms. The previous 07b design has 637,850 triangles; the stock-only design has 582,946. All triangles are retained in the whole-part views. The closeups select actual surface triangles inside the documented display boxes; they are not thickness sections.

The first main-window cut-profile inset changes from **1.5 mm to 2.8 mm**. This parameter is not wall thickness. The stock-only design also omits the old 07b blend, so the figure does not attribute every visible difference to the inset alone. The two other main windows and all outer-stock branches retain their original inset; all 12 effective branch rows are preserved in the geometry delivery.
