# Fichiers des pièces

Structure attendue :

```text
parts/<part_id-lowercase>/
├── source/       FreeCAD, OpenSCAD, scripts et entrées autorisées
├── derived/      STEP, 3MF, STL et plans exportés
└── evidence/     mesures, rapports et photographies autorisées
```

Les scans bruts et documents tiers ne doivent pas être ajoutés sans licence
explicite. Les fichiers lourds exigent une décision de stockage avant commit.
