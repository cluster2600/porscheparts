# Preuve d'assemblage — roues Fuchs 18 pouces

La documentation fabricant et l'homologation ECE R124 relient la roue
`37027.011`, 8J x 18 ET52, à l'essieu avant et la roue `37028.011`, 10J x 18
ET65, à l'essieu arrière du type 993.

L'ensemble courant couvre le montage logique Carrera. Le montage Turbo n'est pas
créé tant que l'entretoise arrière de 25 mm exigée par la documentation n'a pas
sa propre fiche physique complète.
