Mesh (both cases, generated by `make_case.py`): 192 hex cells.
3 axial zones (up 4H | disc | dn 8H) × 2 radial layers (hub→R_mid, R_mid→throat,
R_mid = hub + 0.4·H) × 4 angular quadrants; hub and throat are no-slip walls
(no wedge singularity); uniform axial cell count so block merging succeeds.
checkMesh: **Mesh OK** both cases; max skewness 2.50, non-orthogonality ≈ 0,
max aspect ratio ≈ 166 (flagged OK by checkMesh; axial:radial cell ratio — see
limitations). `discCells` cellSet = 64 cells (topoSet boxToCell over the disc block).

Fan model: actuator-disc SURROGATE (fvOptions, one `vectorCodedSource` over
`discCells`): `Su = −β·|U|·U + Δp/V_disc·x̂`. Quadratic blockage proxy + prescribed
static rise. No blades, no rotation — blade count is UNKNOWN (M64-ACQ-0005;
parallel lane deriving it from the fan-drive scan).

## What this proves vs what it does not

**Proves:**
1. The container (OpenFOAM v2312) can build, mesh, check and solve a fan-zone
   deck end-to-end: blockMesh → topoSet (cellSet selection) → checkMesh →
   simpleFoam with fvOptions coded sources. The toolchain lane is live.
2. A parameterised generator + runner produces deterministic, reviewable cases
   with provenance-tagged inputs.
3. The deck responds correctly to the F0 geometry failure direction (case A
   higher loss than case B), and mass-balance closes to <0.01 % on the prescribed
   flow.

**Does NOT prove:**
1. **Any absolute fan performance.** Δp_fan and β are assumptions; the published
   1010/1210 l/s are imposed as inlet BCs, not predicted. A measured fan map and
   system curve are still required.
2. **The geometry.** Throat 252/284 mm and impeller 280 mm are F0 hypotheses;
   the real throat, impeller diameter, hub, axial position and clearance are
   unmeasured. Case A's −14 mm clearance is documented, not simulated (impeller
   is outside the fluid domain in both cases).
3. **The fan physics.** No blades (count UNKNOWN → **M64-ACQ-0005**), no
   rotation, no tip-clearance jet, no swirl, single duct instead of the real
   split plenum/duct network, isothermal 20 °C air, coarse 192-cell mesh with
   aspect ≈ 166.
4. Mesh-check pass ≠ engineering validation; residuals not fully converged;
   everything on this deck stays labelled **exploratory / placeholder-BC**.

**Next inputs that would change conclusions:** ACQ-0005 (blade count, pulley
diameters → real fan speed and Δp scaling), measured housing throat / impeller
OD / clearance (replaces G-01…G-03), a measured fan map or bench flow test
(replaces M-02), bay air temperature, and real duct geometry for the discharge
network.
