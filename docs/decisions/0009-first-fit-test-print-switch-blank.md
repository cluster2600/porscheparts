# 0009 — The first printable file is a fit-test kit for the switch blank

Date: 2026-09-25

## Context

The active phase manufactures nothing ([ROADMAP.md](../../ROADMAP.md),
"Physical prototypes — suspended"). After a whole catalogue of concept records,
the project owner asked for one part that can be printed today.

None of the 34 records has measured geometry. Printing any of them as "the part"
would present a guess as a fit. Among them, only three are `non_critical`, and
only two are meant for FFF: the dashboard switch blank
(`993-INT-SWITCH-BLANK-0001`) and the seat rail cover. The switch blank has a
published, if weak, figure for its opening — about 19 × 31 mm, level C — and
its failure creates no immediate hazard.

## Decision

The first printable file of the repository is a **fit-test kit** for
`993-INT-SWITCH-BLANK-0001`: three blanks on one plate whose insert brackets the
declared opening (−0.4, 0.0 and +0.4 mm), marked 1, 2 and 3 on the back,
generated by `parts/993-int-switch-blank-0001/source/fit_test_kit.py`, sliced
and published in `parts/993-int-switch-blank-0001/print/`.

- The kit is a **measurement instrument**, not a released part: the record stays
  at `concept` until a fit result is recorded.
- The exception covers this part only. It does not relax SAFETY.md for any
  functional, safety-critical or metal part.
- The measurement-driven master (`source/switch_blank.py`) is unchanged: it
  still refuses to build until D01–D07 are recorded.

## Consequences

- The repository now contains a file someone can print, clearly labelled as a
  fit test, with its sizes and all its hypotheses listed.
- A fit result becomes the first physical evidence in the catalogue, and the
  first step off `concept` on the validation ladder.
- If none of the three sizes fits, that result is recorded too: it says the
  declared opening was wrong, which is worth knowing before anything else is
  built from it.
