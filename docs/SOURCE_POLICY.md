# Politique des sources

## Hiérarchie de confiance

| Niveau | Type | Usage |
|---|---|---|
| A | Mesure directe traçable ou document officiel | Dimension ou spécification de référence |
| B | Fabricant, équipementier ou norme | Matière, procédé, composant |
| C | Mesure communautaire reproductible | Recoupement ou géométrie secondaire |
| D | Modèle tiers avec licence mais précision non démontrée | Référence visuelle uniquement |
| E | Estimation depuis photographie ou rendu | Hypothèse explicitement marquée |

## Règles

- Une donnée publique n’est pas automatiquement libre de droits.
- Une capture ou un scan sans échelle n’est pas une mesure.
- Une vue éclatée renseigne l’assemblage, pas nécessairement les dimensions.
- Deux sources qui se recopient ne constituent pas deux confirmations.
- Les documents protégés restent hors du dépôt ; la fiche conserve leur référence.
- Toute contradiction reste visible jusqu’à résolution.

## Audit d’un modèle 3D

Enregistrer : auteur, URL, licence, format, variante, nombre de pièces, présence de
l’intérieur ou du soubassement, unités, dimensions déclarées, possibilité de
modifier et redistribuer, et résultats de comparaison avec les dimensions connues.
