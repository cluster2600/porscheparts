# Groupe C — Relevé public des motorisations Porsche 911 1982–1998

Relevé external (agent de recherche, read-only) du 2026-09-27 pour le lot
« Groupe C research 1982-1998 » (période G-model : Carrera 3.2 / G50, type 964,
type 993). Chaque valeur porte un niveau de preuve. **Rien ici n'est une mesure
du projet** : aucune valeur ne promeut une géométrie au-delà de `F1_envelope`
sans métrologie (règle ADR-0004 déjà appliquée dans
`docs/research/m64-public-engine-data-2026-09-27.md`).

Niveaux : `FACT_public` = publication constructeur (brochure, manuel usine) ·
`CROSSCHECKED` = deux sources secondaires indépendantes concordantes ·
`SINGLE_SOURCE` = une seule source secondaire · `ASSUMPTION` = inférence.

## 3. Continuités techniques utiles au jumeau M64

- **Continuité 930/60 → M30/69 → M64/50 → M64/60** : la famille Turbo passe par
  trois blocs distincts (3.3 G-model carry-over, 3.6 simple turbo, 3.6 biturbo).
  Le jumeau ne doit pas fusionner les interfaces d'échappement/suralimentation
  de ces trois générations.
- **Géométrie de base commune M64** : 100 × 76,4 mm apparaît identique du M64/01
  (964, 1989) au M64/60 (993 Turbo, 1998) — alésage et course publiés concordants
  sur les deux articles. C'est un contrôle d'échelle fort pour le squelette
  paramétrique (`FACT_public`).
- **Boîtes d'échange de couple** : G50 / G50/10 / G64 / Tiptronic (964) puis
  6 vitesses standard + Tiptronic (993). Les interfaces moteur↔boîte changent de
  génération à génération ; à traiter comme variantes séparées.
- Le 964 a introduit la 4RM (Carrera 4, issue du 959) reprise en 993 avec
  coupleur visqueux. Attention aux 4RM Turbo : sur 964 (Turbo 3.6 « 36/35 »
  Limited) et sur 993 (Turbo 3.6 Exclusive « X64/Ext.4 »), la 4RM a bien été
  offerte en option sur les Turbo ; la formule exacte pour le 993 Turbo de
  série reste **D — piste à vérifier** avant usage.

## 4. Lacunes / contradictions à conserver

- **Type 64 / projet 965 (années 1980)** : souvent cité comme programme
  avorté (variantes ~2,6 / 3,1 / 3,7 / 4,0 L, dont un dérivé F1 atmo). Aucune
  source consultée ce jour ne le confirme ; l'article Wikipédia « Porsche 965 »
  redirige vers l'article 964. Le « 965 » comme code moteur Type 64 reste
  **D — piste non vérifiée** ; ne pas l'utiliser.
- **993 Turbo de série et 4RM** : l'article 993 consulté mentionne une
  disponibilité 4RM pour la gamme sans ligne dédiée au Turbo ; la question
  (options X64/Ext.4, Turbo 3.6 Exclusive 4RM) reste ouverte, sans contradiction
  relevée mais sans preuve positive ce jour.
- **959 (1986–1993)** : 2,85 L biturbo DOHC 24 soupapes, culasses refroidies
  eau (95 × 67 mm, 450 PS) — famille dérivée G-model mais hors lignée M64 ;
  croisé ici seulement pour la génétique 4RM/biturbo.
- Puissances USA/CDN/JAP systématiquement distinctes des versions européennes ; ne
  jamais mélanger deux marchés dans un même profil de puissance.
- Chiffres GT2 R / GT2 Evolution (compétition) : réglages dépendants du boost,
  à garder comme variantes non routières.
