The previous eleven-region bare-head study was classified on a closed,
constructed envelope. This increment applies the **same three stock planes and
fixed classifier directly to the original admitted acquisition**. Only **five
provisional geometric domains** have a single source-supported simple closed
section and pass the unchanged classifier. Anatomy is not accepted. There is no
proven one-to-one correspondence between the eleven proxy regions and these
five source regions.

The result advances source/component separation while retaining ambiguity:
**64,458** wholly outward original triangles are separately represented, and
**2,401,378** original triangles remain in an unclassified retained surface.
That retained surface includes all **726** crossing triangles unchanged; the
other **204** quarantined triangles remain in the original acquisition. The
three counts sum to all **2,466,040** acquired triangles. No source triangle is
clipped, welded, smoothed, moved or capped. A closed section curve is not a
closed part.

[Aggregate execution results](results.json) bind the actual private outputs,
executed sources and checks. Scan arrays, face IDs, STEP, BREP, OBJ and native
documents remain in the private evidence capsule, outside Git and external

is needed for this bounded local increment. The earlier paid instance remains

## Original-source admission and independent rejoining

[The producer](source/audit_source_cuts.py) bounds the sign of each original
vertex/plane expression and uses exact rational fallback when ambiguous. A
vertex exactly on a plane causes refusal rather than plane jitter. Its sparse
graph connects outward triangle portions only across an original edge that has
a positive portion. Sharing an entirely negative edge cannot connect two
outward regions. Original edge IDs define section nodes, so nearby points are
never joined by distance.

The producer evaluates edge intersections as exact fractions of the stored
binary source coordinates and plane coefficients, then rounds once for native
construction. A candidate requires one degree-two section cycle. Open,
branched and multi-loop components remain unresolved. The three planes have
11, 3 and 13 outward source components respectively; only 3, 1 and 1 pass the
fixed classifier. Other closed loops can fail size/shape/extension criteria.

[The independent checker](source/check_source_cuts.py) rebuilds connectivity
with dictionaries and disjoint sets, checks the **whole partition bijection**,
rejoins every crossing original face and edge, and reconstructs rational
intersections with a separate formula. It validates all ordered loop segments,
compares vector-area and perimeter calculations, and uses exact planar
predicates to reject crossings, backtracking and overlapping/nested selected
domains. Selected source-face sets must also be disjoint across planes.
Maximum independent metric difference is below `1e-8`; that is arithmetic
agreement, not metrology.

## Actual native geometry and readback

[Native construction and a separate readback mode](source/native_source_regions.py)
create five exact-source STEP patches and five closed polygonal section wires
in OCCT BREP. STEP patches use the already qualified source builder and
independent reader, preserving original coordinates, winding, edge adjacency
and vertex fans. Source point-contact fans can be separated at unchanged
coordinates. Every patch is valid and has zero solids; the first has two source
shells and the other four have one. Boundary edges remain explicit.

Actual native STEP reinspection requires **zero original-vertex error** and
every selected original triangle exactly once. Section wires are constructed
geometry: their ideal rational endpoints, once-rounded endpoints and stored
native endpoints are distinguished. BREP preserves a native wire container;
the reader requires one closed wire, the exact expected consecutive line
segments, unique endpoint matching, validity and zero faces/solids. The
`1e-8` nominal-mm constructed-endpoint guard is not a physical tolerance.
Actual maximum native section readback error is below `5.2e-13` nominal mm;
ideal-to-once-rounded error is below `2.9e-14` nominal mm.

Before head export, separate native processes construct and inspect a
nontrivial decimal rectangle. A wire with the same vertices/counts but crossed
segments must fail for the segment-origin reason. No source-export run starts
before those controls pass. [The bounded native controller](source/run_native_regions.py)
retains actual exit codes, sampled child RSS, elapsed time and child reaping.
The shared limit is 600 seconds, child RSS 4 GiB and disk floor 4 GiB.

[The FreeCAD macro](source/create_region_document.py) assembles the five source
patches and five section curves as ten separate editable reference objects,
with identity placements, source hashes and false physical/manufacturing
flags. A fresh process exports the actual stored shapes for independent
original-source and rational-section reinspection. Merely saving a document or
matching shape counts is not geometric acceptance. This is a faceted review
document, not a parametric head or a boolean hardware-removal operation.

[The retained-surface exporter](source/export_retained_source.py) writes an
open OBJ reference with 17-significant-digit coordinates. A separate streaming
parser rejoins every actual stored vertex and ordered triangle to the original
arrays through the bound private source-index mapping. The retained NPZ keeps
the source IDs and all transition faces. Neither export is advertised as an
STL, 3MF or manufacturing job.
