Status: installed and executed on Kali1/ext4, 2026-11-04. A new private Python
environment can construct and independently inspect the registered acquired

and zero solids**. All eight original-triangle/topology checks pass. Vertex
coordinate error is recorded as 0.0 mm; normal-dot error is 4.44e-16; native
plane/corner discrepancy is 1.27e-11 mm. Explicit millimetre units are checked in
the STEP text. No acquired coordinate changes, smoothing, cylinder fit, gap fill
or hidden surface is introduced.

The builder's two native controls and four input refusals pass. A separate
verifier reloads both actual fixture STEPs against independently stated unit
square/point-contact geometry, checks their source topology, explicit millimetres
and actual zero solids. A deliberately substituted square STEP is refused as
the acquired region, for the expected source-coordinate mismatch reason; no
successful verification output is published for it.

All **29 recovered result files** match their remote manifest and archive hash.
The actual Linux-produced STEP is then reloaded on the Mac, under the existing
outbound-denial profile, and checked against the original arrays again. The
same original geometry/topology checks pass. This is cross-host reinspection of
one artifact, not a second independent mathematical algorithm or new source
coverage. The 2,790 faces already belong to the 21,472-face native reference;
they are not added again to its coverage denominator. The existing FCStd master
and original OBJ remain unchanged.
