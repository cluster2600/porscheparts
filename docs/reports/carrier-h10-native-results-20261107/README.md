# H10 public scalar figures

Copy `render_v2.py` and `figure-inputs.json` into a fresh empty directory, then run `python render_v2.py`. The recorded runtime is Python 3.12.13 and Matplotlib 3.10.8. The renderer checks the fixed input SHA-256 and preserves the original plotting calculations. It creates two PNG files and a small figure receipt, refusing existing outputs.

This is a scalar-figure replay, not a native solve, field decoder or scientific admission. PNG byte parity is checked in the recorded runtime only; other fonts or Matplotlib versions may change rendered bytes.
