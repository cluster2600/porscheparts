# Preuve d'assemblage — roues Fuchs 17 pouces

Le document fabricant relie explicitement la roue 7J x 17 ET55 à l'essieu avant
et la roue 9J x 17 ET55 à l'essieu arrière du Porsche 993, à raison de deux
unités par position sur le véhicule.

La fiche reste `logical` : elle ne contient ni pose 3D, ni géométrie de moyeu, ni
validation de collision. Aucun PDF tiers n'est copié dans le dépôt ; seule la
référence du document public du fabricant est enregistrée.
