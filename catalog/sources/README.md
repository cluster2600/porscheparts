# Source register

A JSON record represents a potential source: official catalog, manual,
measurement, 3D model, photograph or dataset. It records technical access,
reading method and reuse rights separately.

An accessible page is not necessarily redistributable. A page read in a browser
is neither an authorized download nor a validation of accuracy.

Create a record from `catalog/templates/source-record.json`, then run `make check`.

Contradictions between records, the official sources that cover each family of
the 993, and dated model-year and availability observations are kept in
[`catalog/registers/`](../registers/README.md). Absence from the Porsche Classic
Parts Finder or from a vendor search is not proof that a part is discontinued.
