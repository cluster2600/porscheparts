# Multilingual M64 measurement research, 2026-10-25

This increment contains **30 authored records**: 29 qualified
supplier/factory declarations and one explicitly unresolved signed dimension.
It links 19 reviewed source representations in English, German and
Japanese. Searches also covered Chinese, Italian, French and Spanish; a search
language does not imply that a qualified source was found in that language.
No physical component was measured.

The [research report](../../../docs/research/m64-world-measurements-20261025/README.md) explains the
applications, datums and limits. The [training pack](../../../training/m64-world-measurements-20261025/README.md)
prepares attributed CPT/SFT data without running a model-training job.

| File | Purpose |

KTS, Carrillo, Molnar, Web Cam and NAPREC dimensions belong to their named
aftermarket products. Turbosmart actuator dimensions belong to its stated
product or generic IWG75 drawing. The Porsche 956 geometry belongs only to the
identified Type 935/76 configuration. None establishes an original M64/60 wall,
a machining drawing, validated fit or an engine power rating.

Only authored factual paraphrases and metadata are redistributed. Raw manuals,
catalogues, HTML responses, workbook files and page images remain outside Git.
