# German-source turbo and materials register

This increment contains 108 authored factual records, 27 captured-source
metadata entries, and five additional bibliographic readings. Twenty-five
source entries are German, one is German/English, and one English aftermarket
page was discovered through German queries. Three journal landing pages were
inspected only as public abstracts and bibliography; their unread full texts
create no technical targets.

See the [research report](../../../docs/research/mezger-german-sources-20261003/README.md)
for comparison tables and the [training pack](../../../training/mezger-german-sources-20261003/README.md)
for build, partition and verification instructions.

| File | Contents |

The register distinguishes Porsche factory statements, retrospective accounts,
supplier declarations, generic alloy/process data and explicit uncertainty.
Aftermarket RR350/2618/713C data do not establish original Porsche grades.
Machining allowance, coating thickness, stock-product size and heat-treatment
wall-scope limits remain distinct quantities. No missing original component
thickness or compressor map has been filled by inference.

Source documents remain their publishers' property. This register contains
metadata and original factual paraphrases; raw captured documents are excluded.
The earlier materials register and both earlier training packs stay unchanged.
