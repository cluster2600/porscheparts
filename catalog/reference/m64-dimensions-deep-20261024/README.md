# Deeper engine dimensions register

This supplement contains 49 records: 40 retained records and 9 excluded leads.
Twenty canonical sources are linked, including 17 new records. No physical
component was measured. Exact product, edition, measurement datum, conditions
and unresolved source discrepancies remain attached to every value.

See the [research report](../../../docs/research/m64-dimensions-deep-20261024/README.md)
and [training pack](../../../training/m64-dimensions-deep-20261024/README.md).

Piston dome height, top-land width and cylinder collar-height datums are distinct
from material wall thickness. A replacement-valve OE cross-reference does not
prove every original part's manufacturing dimensions. Source conflicts keep
separate products and editions; the printed 25-degree valve-seat entry remains
uncertain. Excluded event-angle text and unread manuals create no targets.

Only original factual paraphrases and metadata are redistributed. Raw source
documents/images/readers are excluded. Four earlier data packs, manual registers
and existing source files remain unchanged.
