# Import documentaire iCloud Porsche

Voir le [bilan d'intégration](../../../docs/ICLOUD_PORSCHE_IMPORT_2026_09_06.md).

- `workbook-data.json` : neuf feuilles du classeur, cellules et formules avec
  provenance. Aucun résultat ne constitue une mesure physique du projet.

  checkout avant import et provenance des 25 nouvelles fiches de sources.

Les données restent documentaires et non revérifiées. Elles ne sont pas
consommées automatiquement par les générateurs de géométrie ou les solveurs.
