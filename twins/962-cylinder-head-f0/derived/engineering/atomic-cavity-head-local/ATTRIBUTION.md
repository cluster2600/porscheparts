# Attribution and record boundaries

This capsule assembles exact selected original records and explicitly named
whitelist projections. It does not contain full native records or provide
standalone reproduction of the head calculation. Original record hashes and
complete input/artifact inventories identify the retained evidence.

The native report, predeclared reference, corner-start addendum, exact pair
table and five review/refusal records are byte-identical copies. Their original
identities appear in `original-records.json`. The pair table remains labelled
as a pre-execution RAM prediction; the actual full-array reviews independently
bind all 933 pairs to the saved candidate. A lifecycle projection is assembled
from the original phase/execution/child records, with raw commands, owner and
container identities, machine paths and control stdout omitted.

The initial peer-assessor refusal concerned Docker mount-list ordering and
stopped before array checks. The corrected comparison keeps every unique
destination/source/type/read-write field exact. Its preserved postcheck records
this assessor correction; no native output, reference or numerical predicate
changed. This was not a native geometry failure or retry.

Project evidence is covered by `LICENSE.project`. CGAL, its runtime image and
compiler have their own licences; no CGAL headers, executable, private runtime
or full head arrays are distributed here. Hashes identify those dependencies.
