# Independent actual atomic-fixture assessment method

This freezes a readback method while compilation is running. No native fixture result is credited here. The only references are the complete literal arrays in frozen expectations `2a6993b7...`, freeze `9584ca30...`, and pure preparer `89a2af8e...`; the preparer's `run()` is never invoked. `assess_literals.py` imports only its pure arithmetic definitions after checking all three hashes, with bytecode writing disabled. The assessor itself has not been invoked against outputs.

For a completed separately reviewed fixture phase, first independently verify its exact child, complete before/after/current pin maps, source/binary associations, all artifact byte counts/digests and exact directory closure. Inspect each actual execution receipt for the declared return code, immutable image/mounts/resources, no OOM, stopped exact ownership, attach reaping and removal. Compile success or procedural phase completion does not establish a fixture result.

The fixed expected return codes are known-collapse **0**, all-fixed **3**, four-vertex-disk **0**. For each successful case compare every binary64 coordinate byte in output vertex order, every origin byte, and every oriented face in creation order against the literal reference. Cyclic rotation of a triangle's starting corner is canonicalized; reversal and row permutation are refused. Recompute complete exact-dyadic normals, signed volume and poor-face classifications, all triangle-quality values/minimum, edge/vertex manifoldness, component/Euler counts, orphan/duplicate absence, all original fixed-coordinate bytes and exterior oriented faces, and the full affected oriented boundary. Preserve any native/reference floating-point mismatch; no tolerance is added. Exact signed volume is 3511808 mm³. Both successful outputs must be9V/14F, with zero poor faces, four surviving affected star faces and eight actual final affected-neighbor checks (four internal plus four against exterior neighbors), zero envelope/normal/duplicate/area-ratio/dihedral failures, and every native guard true.

The all-fixed case must contain only its rejection report. Its stage is `input_association`, before the `inputs` guard is established or a quotient is constructed: candidate-built and quality-checked false, minimum null, no candidate/origin filenames and no export. Original inputs must remain unchanged. Default zero report counters are not quality measurements.

The assessor covers the complete tiny candidate arrays and report semantics. Execution, immutable-binary/source association, before/after pins and phase artifact closure remain a separate full retained-record review. It neither replays CGAL nor supplies native envelope measurements. No head result, global embedding/distance acceptance, volume meshing, solver result, engineering approval or manufacturing qualification follows.
