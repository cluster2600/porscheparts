Use the release's `USD_REVIEW_SHA256SUMS.txt` and `USD_REVIEW_ARCHIVES.json` to verify downloads. [archives.json](archives.json) preserves the packaging record created before upload; [publication-receipt.json](publication-receipt.json) records the completed live verification. All six new server SHA-256 digests and sizes match local files. The twelve older asset IDs, bytes, digests and uploaded states remain unchanged, making eighteen assets in the same draft release.

The [four-case manifest](../usd-exact-family/manifest.json) records complete oriented-triangle parity, zero bounds discrepancy and eight successful official minimum USD checks per case. Every file uses millimetres, Z-up, the original frame and subdivision disabled. The images are earlier STL study renders, not USD/RTX renders.

The USDC files preserve the inspected project geometry. They contain no assigned physical material, simulation fields, fluids or engine assembly. Historical dimensional fidelity, fitment, complete SimReady validation, head strength/thermal/fatigue results, calibrated LPBF and manufacturing acceptance remain open. No runtime is bundled or manufacturing release authorised. Original geometry and English review archives remain separate and unchanged.
