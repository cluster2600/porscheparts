# Partial head application of the apex 1474426 local cavity

One native application replaced the original complete 60-tetrahedron star with
the previously reviewed 101-cell local candidate. The saved head has 1,097,057
nodes, 3,620,861 TET4 cells, 225,326 referenced interior nodes and no observed
orphans. Procedural and saved-reopen checks completed. The unchanged whole-head
SICN threshold of 0.1 still rejects the result: 204 positive poor cells remain,
with minimum SICN 0.039074265058645995. The parent had 208 poor cells. The count
prediction is not an acceptance gate. The 101 inserted cells pass locally, with
minimum native SICN 0.13807503254019585.

The worker reports preservation of all outside coordinate words and ordered
cells, original classifications, source boundary and lower-dimensional/entity/
physical/periodic metadata. It reports complete global native quality, signed
volume and face-incidence audits, and exact after-to-saved-reopen identity.
These global geometry observations and native reloads are worker-attributed.
Root and the independent reviewer checked saved associations and reconstructed
all 101 local-to-global ordered rows and all 303 local native metric words.
They did not independently decode the full head MSH or recompute global quality.

The independent checker's first attempt returned RC1 because it compared a
six-field preservation dictionary with an eleven-field context dictionary. The
one-line corrected attempt returned RC0. Both sources, executions and streams
are retained; no worker/result mismatch or second native edit is implied.
Root's contemporaneous result-review field saying the peer was pending remains
unchanged; the later independent peer and root's acceptance of that review are
included separately. This resolves the pending review, not the quality rejection.

The native worker and controller returned naturally with RC2 and no watchdog
stop. Root wall time was 238.26962741697207 seconds. Controller sampled maximum
RSS was 4,880,629,760 bytes; this is not a true peak or a hard OS memory quota.
Root records its observed owned controller/worker pair, reaping and individual
absence. This does not establish universal process absence. The 56 input hashes,
three selected native-runtime identities and selected NumPy initializer were
unchanged according to root. They are a selected binding, not complete ABI,
package, operating-system or environment closure.

The full seven-file output inventory is retained. The 235,744,782-byte head MSH
is not included, copied, read or hashed by this publication assembly. Its

`4c6543f8e905c2771f9f313e5e131d06d081928deafb8dd5b43b18d9d2c73a3f`.
