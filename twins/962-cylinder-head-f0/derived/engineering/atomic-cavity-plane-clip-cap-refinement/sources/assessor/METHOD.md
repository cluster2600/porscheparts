# Stopped cap-only output assessment

`assess.py` uses only the Python standard library. It does not import the extractor, a CGAL/native module, the C++ program or any scientific package. Whole-file SHA-256 pins guard AST extraction of the existing exact codec/vector/connectedness functions and the existing oriented-chain/cycle helpers. The open-cap edge and vertex-link audit is a separate small adaptation of the retained closed-surface audit.

API: `assess(cap_path, map_path, fixed_path, native_output_directory, actual_returncode, expected_sha256)`.

CLI: `assess.py cap.bin map.u64 fixed.u64 native-output RC bindings.json bindings-sha256`.

The caller must supply hashes from an independently retained authoritative capture/manifest and the actual external native return code. The CLI verifies the explicit bindings-file hash. Every consumed input and output must be present in that map and match before assessment; consumed hashes are rechecked afterward. The assessor does not authenticate a newly self-generated manifest, attest a native process, or verify its lifecycle. The passed directory is the source's native payload directory, not an enclosing phase directory containing execution receipts.

For RC0, all four native payloads are required and no extras or symlinks are allowed. Checks cover the complete input and output codec/arrays; finite and numerically unique coordinates; unique valid faces and no orphan points; negative-Z winding; every exact stored-coordinate q>=2/29 predicate; full oriented edge incidence, complete boundary/interior vertex-link paths/cycles, one component/Euler0/two boundaries; the complete mapped oriented boundary; old-point byte identity and every new point's UINT64_MAX origin; every selected fixed triangle and face-source ID; original/mapped/reconstructed exact areas; and all relevant binary, map, fixed, constraint and refinement-insertion report counts. Head inputs bind 38 fixed face IDs externally; the same assessor supports the tiny synthetic fixture's single fixed cell without a hardcoded head count.

The exact minimum q-squared is independently computed as a rational. The reported native scalar minimum and native active default-shape census are retained as observations, not independently reconstructed from the native operation sequence. A native queue can exhaust with unresolved stronger shape requests; a false `CGAL_CDT_active_shape_criteria_satisfied` flag is allowed if the independently checked final q gate passes. Full polygon/domain coverage, self-intersection absence, the native refinement algorithm and new-point rounding history are not independently replayed here. Boundary, winding, area and combinatorial checks must not be promoted into an independent self-intersection certificate. The complete head remains unadmitted.

For RC3, report-only closure and the exact stage-dependent prefix of observed native guards are mandatory. Later fields and initialized zero counters remain unobserved and receive no pass credit. No candidate/provenance payload may exist. RC2/errors are not accepted by this assessor. Invalid fixed-association or mapped-loop refusal need not satisfy the successful map/fixed semantic predicates; their bound input bytes and report-only status are checked without claiming an independently reproduced native reason.

These tests are not actual native cap outputs or proof of Steiner refinement. Root/peer source review and a separately bound native run remain pending.
