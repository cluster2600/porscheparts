# Exact local cavity embedding: all 741 pairs pass

The completed exact query and an independent saved-data reconstruction confirm that **all 741 unordered pairs** of the stored 39 tetrahedra intersect exactly in their shared tagged simplex, or are disjoint when they share no tag. The **41,496 plane triples** were covered without sampling. This establishes pairwise tagged-complex embedding for this local stored-coordinate cavity. It does **not** establish head containment, stitchability or native mesh approval.

The [complete report](reports/embedding.json) preserves every pair association, intersection count and verdict. It records 261 empty intersections, 267 shared vertices, 149 shared edges and 64 shared faces; zero illegal intersection vertices were found. Of the 41,496 tested triples, 40,092 are nonsingular. Each positive tetrahedron is represented by four exact closed inward halfspaces. For each pair, all 56 triples among its eight planes are considered; nonsingular systems give potential vertices, retained only when all eight exact inequalities hold. A nonempty bounded intersection, including a face, edge or point intersection, has vertices whose active normals span ambient three-space. Thus this enumeration covers its vertices. The convex hull of shared tagged nodes is contained in both tetrahedra; checking that every intersection vertex lies in that shared simplex establishes equality. Unshared geometric contact would fail this tagged-complex condition. The [source and method](sources/METHOD.md) state the proof, exact shared-point/segment/triangle tests and duplicate-cell refusal. No tolerance, grid, perturbation or scientific geometry backend is used.
