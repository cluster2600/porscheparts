# Full-head cap/side assembly — source preparation only

This 100-line-scale standard-library script performs one deterministic byte/index assembly after separate root/peer source review and completed cap-result reviews. It has not been imported, tested, executed or used to load/assemble head geometry here. It does not run any native or scientific package.

The fixed inputs are clipped head d2af, the exact original cap extraction and both local→d2af provenance arrays, the complete1222-row mixed keeper function (506 identities/716 contractions), the checked mixed-side report, and actual source002 cap BIN/vertex origins/face origins/report. An authoritative stopped cap Fraction assessment must cover all seven consumed cap input/output files with matching hashes; separate root and independent result reviews are mandatory. Pending review entries or false held flags refuse before output creation.

Every original cap coordinate and ordered oriented source triangle is re-associated byte-for-byte with d2af. The complete keeper map is matched against all506 saved groups. All3,508 old cap faces are replaced. The global map is applied to all noncap faces; exactly the saved716 degenerate side faces may drop, and every changed surviving source face ID must match the saved mixed-side census. All other oriented noncap rows retain their source order and mapped indices. Every output old coordinate copies its d2af bytes. The3,092 new cap points copy their native binary64 bytes directly.

Output coordinate order is ascending uncontracted d2af IDs, then new interior points in native-cap vertex order. The expected assembly counts are871,731 vertices =869,355−716+3,092 and1,743,878 faces =1,739,126−3,508−716+8,976. These are a source-bound construction expectation, not an observed new mesh. No additional orphan removal is allowed. The eight payloads are the candidate SURF1, complete coordinate/face origins, old→new vertex/face maps, cap→head vertex/face maps, and new-interior-point→native-cap vertex IDs. Old→new vertex IDs include many-to-one contractions; removed/retriangulated old faces map toUINT64_MAX except the38 exact fixed cap cells, whose new locations remain known. Complete serialized output bytes are reread and compared, and all bound inputs/review records/runtime are rehashed. The producer checks codec/index/provenance/expected-drop/orphan/count consistency only.
