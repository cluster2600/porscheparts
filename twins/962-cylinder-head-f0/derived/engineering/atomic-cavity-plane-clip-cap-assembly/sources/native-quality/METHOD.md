This is an uncompiled, unrun read-only adapter for the observed assembled surface, not another repair. The selected assembly is 871,731 vertices / 1,743,878 faces, SHA `9d62eac6e2cd7b6a9ecb4a7ea5b632685820369b5c4ede379acc34238f50d7b4`. Its independent byte review is bound separately. No surface or provenance file is written by this adapter; the sole native output is a JSON report.

`audit_native original-d2af.bin assembled.bin vertex-origins.u64 face-source-ids.u64 fresh-output-directory`

The fresh `native_prefix.hpp` contains exact byte slices from frozen `quality_patch.cpp` (read/codec/quality prefix, ending before `Original_projection`) and `atomic_policy.hpp` (the complete `ordinary` scalar predicate). Source offsets and hashes are recorded in `source-reuse.json`. Their original files remain unchanged. The prefix retains a `write_surface` definition, which the adapter never calls, but excludes the old remeshing main and projection body. There is no Mesh_2 invocation, envelope construction or remeshing code path.

The adapter reads both immutable closed oriented surfaces with the existing CGAL reader, validates raw u64 provenance lengths, and checks that every non-sentinel coordinate origin is unique, bounded and bit-identical to its d2af point. Every non-sentinel face preimage is unique and bounded. A face is affected if its preimage is UINT64_MAX, or its cyclic oriented original-ID row through vertex origins differs from its claimed d2af face. A sentinel coordinate also makes a claimed old face affected. This marks all 8,938 new cap triangles plus the independently observed 764 changed noncap survivors: exactly 9,702 affected faces. The 38 retained fixed cap cells remain unchanged. The producer's full provenance proof remains the separately bound byte review, not this partial native check.

`quality()` evaluates every original and every assembled face with the unchanged native arithmetic. The adapter requires full face-count coverage and records the minimum and count strictly below `2.0/29.0`. It then visits every candidate edge exactly once and checks every pair incident to at least one affected face. The four points and call order are copied from source003: `ordinary(a,d,b,c)`. The unchanged policy first requires the larger squared normal magnitude to be strictly less than `1e8` times the smaller; then it applies the existing positive-dot / squared-cosine 1 degree rule. Complete area-ratio and dihedral failure counts are retained, with at most sixteen example edge IDs. There is no arbitrary normal correspondence, added tolerance or relaxed threshold.

Return 0 means only zero poor native faces and zero failures in that complete affected-neighbor scan. Return 3 preserves a completed numerical refusal report. Return 2 means input/API/error refusal; observation flags distinguish complete results from default or partial counters. An existing output directory is never claimed; error reports are written only inside a directory created by this process. A fresh report is never overwritten.

Four literal closed tetrahedra are prepared, not executed. Unit tetrahedra exercise no affected faces and one conservatively new face label (three checked neighbors). Two dyadic slivers exercise the strict area-ratio and near-opposed-normal refusal branches. `fixture-expectations.json` records exact literal arrays and analytical expectations, not measured native results or a floating-point tolerance. For epsilon below 1 the two poor right faces have q = sqrt(3)*epsilon/(1+epsilon^2). Their face-normal squared magnitudes are epsilon^2, epsilon^2, 1 and 1+2*epsilon^2. This gives the declared four large/small ratio failures at epsilon=2^-20, none at 2^-10, and one near-opposed pair in either sliver. No tiny tests or compiler were invoked during preparation.
