# F42.1 — preuves mécaniques publiques

Ce dossier ne doit contenir que :

- le rapport JSON agrégé de l'étude à trois mailles ;
- le graphique de convergence construit depuis ce rapport ;
- ce fichier de portée.

La peau STL privée, la peau réparée, les maillages, les decks CalculiX et les
champs `.dat`/`.frd` restent sur le calculateur autorisé et ne sont pas publiés.
Ces preuves décrivent un écran numérique linéaire fail-closed. Elles ne sont ni
une autorisation d'impression, ni une validation pour fonctionnement moteur.
