# Preuves publiques expurgées F50

Ce répertoire contient uniquement des métriques, empreintes et verdicts. Il ne
contient aucun STEP, B-Rep, STL, MSH, fichier TetGen ni coordonnée privée.

- `native-brep-mesh-f50.json` : synthèse sanitaire OCCT, interop STEP et
  maillages Gmsh/TetGen;
- les maîtres privés restent sur Kali et sont adressés par SHA-256;
- les portes fabrication, impression métal et démarrage restent fermées.
