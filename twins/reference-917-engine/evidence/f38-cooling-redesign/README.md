# Refroidissement 917 F38 — preuves publiées

Deux mailles OpenFOAM 14 d'un canal inter-ailettes sont comparées à une corrélation indépendante de Gnielinski avec efficacité d'ailette. Le canal n'est ni une CHT de culasse complète, ni une validation physique.

- `h` OpenFOAM fin : 201.84 W/m²K ;
- erreur de bilan énergétique fin : 1.77 % ;
- température de pont projetée : 375.8 à 381.2 °C ;
- CHT culasse entière : non exécutée ;
- impression métal et démarrage moteur : interdits.
