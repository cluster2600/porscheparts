# Archive distante du turbo bionique F0/F1

Les sources, tests, rapports et aperçus sont sur la branche
[`codex/bionic-turbo-picogk`](https://github.com/cluster2600/porscheparts/tree/codex/bionic-turbo-picogk).

Les **1023 fichiers de sorties locales** sont conservés dans
[l’archive GitHub d’étude](https://github.com/cluster2600/porscheparts/releases/tag/bionic-turbo-f1-study-2026-10-11) : géométries STL/GLB,
maillages CFD, essais rejetés, diagnostics et journaux. Les 9076398798 octets
bruts sont compressés en 2431461058 octets, répartis en cinq fichiers.
Le document `README-RESTORE.md` joint décrit la vérification et la restauration.

Le [reçu de transfert](remote-archive.json) contient les empreintes, les tailles
et les liens des neuf pièces jointes. Chaque fichier de l’archive a été relu
après compression ; les empreintes de tous les fichiers distants concordent.
Le manifeste complet est joint à l’archive. Environnements Python, caches,
images Docker et outils externes installés sont exclus.

Cette publication pointe vers le commit de conception `387667e0abb14c340cb1cb6a299bd8848e31d403`.
Le présent reçu est ajouté ensuite à la branche et ne modifie pas les preuves
historiques. **Aucun gain de performance, jumeau calibré ou droit de fabrication
fonctionnelle n’est établi par cette sauvegarde.**
