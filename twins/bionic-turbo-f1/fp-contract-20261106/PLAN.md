# Native floating-point qualification: source binding first

Issue #397 requires the actual compiler/options, scalar implementation,
libraries, constants, conversions and operation/branch bounds. Directory names
and `scalar=64` are observations, not sufficient qualification. G04 stays open.

Before arithmetic execution, recover the 180,295-byte native-admission dossier
from its exact historical release URL. Verify archive SHA-256
`c3e889c3d8f28506f95e8bfded8f6775f352824b67ca85488114b1328046e538`
and the original payload manifest. Reuse the existing safe recovery extractor;
do not execute archived programs. Keep all bytes in a new private directory.
Download cap: 1 MiB and 60 seconds. Total new source-recovery storage: 10 MiB.
Reject mismatches, unknown archive members and unsafe links before use.

Read the pinned OSstream/IOstream, scalar/doubleScalar and primitiveMeshTools
sources. Record the exact conversion route and identify which build facts are
still unproven. Bind read-only runtime observations to the immutable OpenCFD
2406 image and binary/library hashes. Preserve failed environment attempts.

Any later arithmetic trial must first prescribe rational-to-text intermediates,
locale, writePrecision 16, signed zero, overflow, gradual underflow, halfway
cases, rounding mode and the actual native reader. Decimal formatting and
binary input rounding have separate errors. Do not assume Python formatting
is OSstream or that sixteen digits guarantee a double round trip.

Operation bounds must follow native evaluation order, constant conversions,
compiler contraction, square root/division error and accumulation counts.
Cancellation needs absolute magnitude bounds. Any interval touching a guard
stays undecided. The independent reader must not import the primary code.

No geometry, candidate, point ratio, mesh, solver or old proof traversal is
allowed by this plan. All 153 closed boxes and both undecided determinants
remain unchanged. Source/build gaps block dependent arithmetic qualification;
an installed runtime compiler would not prove the flags of existing binaries.
